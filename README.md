WetSpot 2 original source code archive
--------------------------------------

This repository contains the original source code of WetSpot 2, a game I made in 1997/98 using QBasic 4.5 and some x86 assembly routines to speed up things where QB couldn't do the job. The game required DOS to work, and eventually worked also on Windows 95/98, but with the retirement of DOS it became impossible to run it on modern systems. The source code is thus provided here for historical purposes only, and is not intended for redistribution or commercial use.

In the original README.TXT file, you can find the full description of the game, its controls, the story behind it and more. The game was a project I worked on during my late teenage years, and it holds a special place in my heart. It was distributed under the "Enhanced Creations" label - a self-created brand I used back then to identify my works - and was widely recognized as one of the best QBasic games of its time; I was very proud of the result and glad to share it with the world.

A port to modern systems was done years ago by Dmitry Smagin, using C and SDL; you can find it here: https://github.com/dmitrysmagin/wetspot2
